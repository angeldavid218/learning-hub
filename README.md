# Agent Labs Portal

Learning hub for [Agent Labs](https://theagentlabs.ai/portal/): a **40-day challenge** with three student views (**Essentials**, **Edit**, **Studio**), a drip sequence via Resend, and an admin portal to manage content.

This repo is the Next.js app (App Router, DaisyUI `agentlabs` theme). Target backend: **Supabase + Drizzle + Resend + Vimeo** (video is not v1).
